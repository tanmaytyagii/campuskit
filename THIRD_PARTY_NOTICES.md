# Third-party notices

CampusKit's own code is released under the [MIT License](LICENSE). The website uses the open-source components listed here, each under its own licence. This page is a summary; the full licence texts are distributed as described below.

## Licence texts shipped with the website

Every production build of the website includes:

- `licenses/third-party.md`: the licence text of every JavaScript package bundled into the site, generated by Vite during `pnpm build` (`build.license` in `apps/web/vite.config.ts`).
- `licenses/archivo-OFL-1.1.txt` and `licenses/ibm-plex-mono-OFL-1.1.txt`: the font licences.
- `licenses/pako-LICENSE.txt`: the licence of pako, which is bundled inside JSZip's browser build.

The source copies of the last three files are in `apps/web/public/licenses/`.

```bash

```

## Development tools

These are used to build and test CampusKit and are not part of the published website: Vite, Vitest, TypeScript (Apache-2.0), ESLint, typescript-eslint, eslint-plugin-jsx-a11y, eslint-plugin-react-hooks, Prettier, tsx, Testing Library, jsdom (all MIT), Playwright (Apache-2.0), and axe-core with `@axe-core/playwright` (MPL-2.0).

## Templates

Each template in `templates/` is a separate project with its own `LICENSE` file. Its third-party components are listed in its README and in the `license.thirdParty` section of its manifest, for example Recharts (MIT) in the expense tracker, and Streamlit (Apache-2.0), pandas (BSD-3-Clause) and Altair (BSD-3-Clause) in the result analyzer. Students install those packages themselves with npm or pip; they are not included in the generated ZIP files.
