# QA report: CampusKit 6.0.0-rc.1

Tested on 31 October 2026 (IST), on the final code in this working copy unless a line says otherwise. Nothing was committed, pushed, published or deployed. Skipped tests are listed as skipped, never as passed.

## Environment

- macOS 26.2 on Apple silicon (arm64), Node.js 24.12.0, pnpm 10.34.7 (Corepack shim)
- Playwright 1.64.1 with Chromium 156 (build 1248), WebKit (build 2370) and Firefox 157 (build 1555)
- Lighthouse 13.6.0 (via `pnpm dlx`) on Playwright's Chrome for Testing, against `vite preview` of the production build
- Docker 29.3.1 for the clean Linux copy

## Problems found during QA, and what was done

| Found by                         | Problem                                                                                                                                                                   | Fix                                                                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Offline e2e (Chromium)           | Cached scripts missed offline when the server answered `Vary: Origin`                                                                                                     | Cache lookups use `ignoreVary`; unit test                                                                                            |
| Offline e2e (Firefox)            | Back online, the "You're offline" notice stayed: Firefox didn't fire `online` for a page it loaded offline (Chromium and WebKit did)                                      | While offline, the notice re-checks `navigator.onLine` every 2 seconds and stops once online; unit test with fake timers             |
| Assistant e2e (WebKit)           | The mocked API wasn't used: requests from a page the service worker controls bypass Playwright's routing, so WebKit sent the fake key to the real API, which answered 401 | The spec blocks the service worker (it never handles API calls). No real key was involved                                            |
| Assistant e2e (axe)              | Answer headings skipped a level                                                                                                                                           | Heading offset corrected                                                                                                             |
| Documents e2e (axe)              | Markdown task lists rendered unlabelled checkboxes                                                                                                                        | Shown as a symbol named "Done" or "Not done"; unit test                                                                              |
| Page tests                       | `workspaceStore.reload()` cached storage at once, so a test seeding storage after another's reset saw nothing                                                             | Reload is lazy, as in the profile store                                                                                              |
| Gallery e2e (WebKit, under load) | A font still loading when the test reloaded the page was cancelled by WebKit, and the fixture counted it as a failed request                                              | The fixture ignores cancellations of fonts, images, stylesheets and media only; script and fetch failures and HTTP errors still fail |
| Repository check                 | Test API keys looked like real ones to the secret scanner                                                                                                                 | Test keys shortened below the scanner's pattern; the scanner is unchanged                                                            |
| `tsc` on e2e                     | A type error in `offline.spec.ts` from M6                                                                                                                                 | Typed correctly                                                                                                                      |

## Why this is 6.0.0-rc.1 and not 6.0.0

1. The AI assistant hasn't made a request with a real key.
2. The Hindi text hasn't been reviewed by a native speaker.
3. The new CI jobs have never run, because nothing has been pushed.
4. Some brief items are partial or deferred, as listed above.

Each of these needs a person or a push to close; none is a known defect.
